# devise-rust-sqlx

sqlx adapter for devise-rust: the `OrmAdapter` seam over sqlx 0.8 with
per-dialect features (postgres, sqlite, and the experimental mysql arm).
Each dialect runs the shared adapter contract suite.

Start at the [workspace README](../../README.md) for setup, guides, and
the feature matrix. API reference: <https://docs.rs/devise-rust-sqlx>
