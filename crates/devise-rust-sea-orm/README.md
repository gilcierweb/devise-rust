# devise-rust-sea-orm

SeaORM adapter for devise-rust: the `OrmAdapter` seam over sea-orm 1.1
with per-dialect sqlx driver features (postgres, sqlite, and the
experimental mysql arm). Each dialect runs the shared adapter contract
suite.

Start at the [workspace README](../../README.md) for setup, guides, and
the feature matrix. API reference: <https://docs.rs/devise-rust-sea-orm>
