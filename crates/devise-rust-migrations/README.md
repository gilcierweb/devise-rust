# devise-rust-migrations

Devise-parity migration generator for devise-rust (ORM-agnostic DDL):
the `devise-migrations` CLI and the `EmitOptions` library emitting
Devise's exact column set per module for Postgres, SQLite, and MySQL.

Start at the [workspace README](../../README.md) for setup, guides, and
the feature matrix. API reference:
<https://docs.rs/devise-rust-migrations>
